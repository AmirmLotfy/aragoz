# Genuine pilot acceptance sessions

Status: no genuine sessions recorded. This packet is ready for a hosted technical preview and does not supply acceptance evidence.

Recruit three first-time invited broadcasters, each with at least three genuine viewers. Record actual attendance and whether each host is first-time; do not count agents, fixture accounts or generated chat. Obtain consent for the particular recording and retain only the minimum useful evidence. Use pseudonyms in public reports. Keep raw moderation/backstage text out of the captured play window.

For each session:

1. Record hosted URL, deployed revision, browser/OS/OBS versions, capture resolution and the actual participants/counts. Confirm setup's genuine chat challenge.
2. Explain movement/strike/dodge and the power-and-flaw command without showing the counter route. Run ordinary authoring, review and two ballots. Record the selected author and genuine command evidence privately.
3. Observe the first two opportunities to trigger an intended counter. Count opportunities and successful triggers; retain event ticks and a recording reference. Give no route hint until the scored opportunities end. Label later assisted play separately.
4. Ask viewers independently which rule won and what effect it had. Score the rule and effect against the committed recipe; preserve short consented responses. Ask what made the attachment stop working without supplying the answer.
5. Finish the show, Encore or Remix, then record confusion, downtime, perceived fairness, boredom, enjoyment, accessibility issues and any host assistance.

Acceptance requires at least two of the three hosts to trigger a counter within two opportunities, and at least two viewers in each session to identify the selected rule and effect correctly. Missing participants or absent evidence leave the gate open. Record actual denominators and failures; do not remove an inconvenient session from the report.

Use template.json for each real session. Leave unknown values null. Keep all AI-led/local/mock tests in their own evidence records. Nothing in this directory authorizes contacting people or publishing a recording.
