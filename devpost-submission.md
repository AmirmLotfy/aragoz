# ARAGOZ

## One-line Summary

Chat makes the monster. You find the loophole.

## Problem

Chat contributions are often fleeting. We want an audience to see its idea become a rule the performer can physically turn against a boss.

## Solution

Viewers propose a power **BUT** a flaw. A reviewed, voted contract attaches a module. The player exploits the flaw, breaks the part, and removes the ability. Credit follows the actual author through selection, activation, break and showbill. The original miniature theatre is inspired by Egyptian Al-Aragoz hand puppetry.

## Why This Matters

The audience writes a meaningful constraint; the performer answers with visible skill. A spectator can trace whose rule backfired. Participation is free and votes are not weighted by spending.

## How We Used AI

Codex assisted development and agent-operated technical testing. Built-in image generation supplied the approved concept sheet and promotional cover. Final original geometry/materials are authored in Blender. Current live interpretation uses a strict supported grammar and six authored profiles; **runtime model calls are disabled**. The optional OpenAI mapping/moderation path is implemented with mocked coverage, not validated with live model calls. No arbitrary text-to-code, mesh generation or per-frame LLM is claimed.

Concrete debugging included immediate damage cancellation at break, protected counter windows, stale-attempt rejection, bounded compiler deadlines, and a genuine authenticated restart/refresh/backup test. ## Key Features

Three acts; two boss shells; charge, steam and delayed echo with two profiles each; two modules per encounter; physical module break/removal; causal attribution; Encore; one-slot Remix; House Suggestions; account-free rehearsal; host controls; accessibility and connection recovery.

## Architecture

Vite/TypeScript/React menus, Babylon.js/GLB stage, pure60Hz combat. Node24/Fastify/WebSockets/SQLite server owns permissions, authoring, votes, deadlines and recipes; the browser owns responsive combat. Original Blender sources and locally shipped assets are retained with rights evidence.
